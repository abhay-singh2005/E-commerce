# Khushnuma Sales | Interactive React Website 🛍️✨
web page link - kushum-sales.vercel.app

## 🌟 Key Features

- **🌸 Ethnic Wear & Festive Catalog**: Heavy unstitched & stitched suits, Banarasi & Organza silk sarees, designer kidswear, and handcrafted men's footwear.
- **📲 Direct WhatsApp Order Integration**: Instant formatted WhatsApp checkout for single items or full cart orders.
- **✨ Instagram Feed & Story Highlights**: Story bubbles with full-screen previews and simulated Instagram post grid linking directly to `@khushnumasales`.
- **🛒 Shopping Cart & Wishlist**: Real-time item counters, promo code support (`KHUSHNUMA10` for 10% OFF), dynamic delivery calculation, and saved wishlist management.
- **📍 Retail Store Info & Inquiry Form**: Complete offline store details (*1011, Biwa Road, opp. HDFC Bank ATM, Firozpur Jhirka*), opening hours, directions link, and custom inquiry submission.
- **📱 Fully Responsive & Fast**: Built with React, Vite, and Tailwind CSS for smooth mobile & desktop experience.

## 🛠️ Tech Stack

- **Frontend Library**: React 18

- **Typography**: Playfair Display & Plus Jakarta Sans

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Navigate to the project directory:
   ```bash
   cd C:\Users\pc\Desktop\kushum
   ```

2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
